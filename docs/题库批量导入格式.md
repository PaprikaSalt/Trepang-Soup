# 私人题库 JSON 批量导入格式

客户端 1.2.0 起可以在“题库管理”中选择 JSON 文件并批量写入私人题库。可以直接复制
[题库批量导入模板](题库批量导入模板.json)后修改。

## 文件结构

```json
{
  "schemaVersion": 1,
  "puzzles": [
    {
      "id": "puzzle_unique_name",
      "title": "仅管理员可见的内部标题",
      "surface": "玩家在游戏中看到的汤面，长度为 20 至 800 个字符。",
      "truth": "完整、自洽的汤底，长度为 40 至 2000 个字符，并解释所有反常行为。",
      "keyFacts": [
        "必须推理出的关键事实一",
        "必须推理出的关键事实二"
      ],
      "active": true
    }
  ]
}
```

## 字段约束

| 字段 | 必填 | 规则 |
| --- | --- | --- |
| `schemaVersion` | 是 | 固定为数字 `1` |
| `puzzles` | 是 | 1 至 1000 道题目的数组 |
| `id` | 是 | 以 `puzzle_` 开头，只能包含字母、数字、下划线和连字符；文件内不可重复 |
| `title` | 是 | 1 至 80 个字符，仅用于题库管理和服务端内部识别 |
| `surface` | 是 | 20 至 800 个字符，玩家可见 |
| `truth` | 是 | 40 至 2000 个字符，结算前只供服务端和 AI 使用 |
| `keyFacts` | 是 | 2 至 8 条非空且不重复的关键事实 |
| `active` | 是 | `true` 允许随机抽取，`false` 仅保存但不参与抽取 |
| `createdAt` | 否 | 非负整数毫秒时间戳；省略时由服务端填写 |
| `updatedAt` | 否 | 非负整数毫秒时间戳；省略时由服务端填写 |

## 导入模式

- **合并导入**：相同 `id` 的题目更新，不同 `id` 的题目新增，其他题目保持不变。这是默认选项。
- **替换整个题库**：导入文件成为完整题库，文件中没有的旧题会被删除。

客户端会在上传前检查文件结构、字符串长度、ID 和关键事实；服务端仍会再次校验。任一题目不符合
格式时，整个文件都不会写入，避免产生只导入一半的状态。
